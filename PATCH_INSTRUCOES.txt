GENESIS LLA V10.7.3 — PATCH HEATMAP DEMOGRÁFICO

NÃO apague o repositório.

1. Extraia este ZIP.
2. GitHub > Code > Add file > Upload files.
3. Arraste o conteúdo extraído, mantendo as pastas src/ e tests/.
4. Aceite a substituição dos arquivos existentes e faça Commit changes.
5. Aguarde Actions > Deploy GENESIS to GitHub Pages ficar verde.
6. Abra Estudos & Gráficos e faça Ctrl+F5.
7. Carregue TARGET ALL, selecione genes e marque:
   "Heatmap demográfico — expressão × sexo/idade"
   ou use o botão "Gerar gráficos", que agora inclui esse heatmap.

O patch NÃO altera CSVs, dados do R, Top 30, DEA, Cox ou Kaplan-Meier.

Método:
- amostras basais deduplicadas por paciente;
- SEX/GENDER + AGE/AGE_IN_DAYS;
- corte etário = mediana da coorte elegível, sem valor clínico;
- quatro grupos sexo × idade;
- média do z-score de expressão por gene;
- mínimo de 5 casos por grupo;
- máximo de 20 genes.
